# poster-kawaii
# 🎨 Poster Kawaii Generator

Web app untuk menjana **Content JSON + Prompt Gemini** bagi menghasilkan poster sekolah bergaya kawaii anime.

👉 **[Cuba sekarang →](https://YOUR-USERNAME.github.io/poster-generator)**

![Contoh Poster](https://via.placeholder.com/400x200/7c3aed/ffffff?text=Poster+Kawaii+Generator)

---

## Apa ini?

Generator ini membolehkan anda mencipta poster pendidikan bergaya kawaii untuk bilik darjah atau taska dengan mudah — tanpa perlu tahu apa-apa tentang reka bentuk grafik.

**Aliran kerja:**
1. Isi borang (tajuk, 6 panel aktiviti, tips)
2. Klik "Jana Content JSON"
3. Salin prompt yang terhasil
4. Tampal terus ke [Google ImageFX](https://aitestkitchen.withgoogle.com/tools/image-fx) atau [Gemini](https://gemini.google.com)
5. Jana poster!

---

## Ciri-ciri

- ✅ Borang mudah — tidak perlu tahu JSON
- ✅ Style Schema sudah terbina dalam (tidak perlu diubah)
- ✅ Jana prompt Bahasa Inggeris untuk Gemini secara automatik
- ✅ Responsive — boleh guna di telefon
- ✅ Tiada backend — semuanya di browser

## Cara guna di GitHub Pages

1. **Fork** repo ini
2. Pergi ke **Settings → Pages**
3. Pilih **Source: Deploy from a branch**
4. Pilih **Branch: main** → folder **/ (root)**
5. Klik **Save**
6. Web app anda akan aktif di `https://USERNAME.github.io/poster-generator`
